# Day 6 — Integration and Security

The integrated path is text or explicit voice input, ASR, the DUTA AI router, deterministic read-only tools or safe AI fallback, full on-screen text, speakable text, and optional TTS playback. Any ASR, AI, tool, or TTS failure leaves the core text path usable.

The integration test matrix covers text and voice-equivalent routing, trusted consulate provenance, Indonesian and Malay routing, provider fallback, unavailable tools, TTS fallback, prompt-injection attempts, no write registry, no trust override, no secret disclosure contract, URL removal from spoken text, and non-persistence contracts.

Trust remains system-derived: A Official Government, B Verified Organisation, C Verified DUTA Partner, D Community, E AI General Knowledge. Only registered read-only tools execute; user text cannot add a tool, upgrade provenance, submit actions, or reveal provider configuration. No new Critical, High, Medium, or Low finding was identified, so Astra review was not required.

Deferred: verified DUTA Map/news sources, NVIDIA TTS provider validation, realtime voice, barge-in, write actions, production migration gates, and historical Git remediation.
