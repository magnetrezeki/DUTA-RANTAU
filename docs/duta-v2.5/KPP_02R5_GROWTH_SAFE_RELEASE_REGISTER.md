Support concerns DUTA itself. Trust Center handles content/user/seller/community
and safety cases; Jaga Diri handles WNI protection/help; privacy requests use
the Privacy workflow. Corporate/investor inquiries concern DUTA's business, not
investment Communities, products, advice or public solicitation.

blocked by a capability, legal, operational or technical release gate. Any
future exception requires an explicit governing authority and must state the
affected user/action rather than converting a capability blocker into a signup
blocker.

## Growth / friction protection contracts

- `PROGRESSIVE_ACCESS_CONTRACT`: Visitors receive the minimum public value first;
  account-gated persistence is requested only at a meaningful Member action.
- `BLOCKER_CONTAINMENT_CONTRACT`: `RELEASE_BLOCKED != REGISTRATION_BLOCKED`.
  A capability gate blocks only its relevant scope; it does not block ordinary
  free Member registration unless an explicit governing authority says so.
- `VALUE_BEFORE_REGISTRATION_CONTRACT`: Public landing, safety/help, trusted
  navigation, and eligible discovery retain value before signup.
- `FREE_MEMBER_CONTRACT`: DUTA Member is free; consumer RM9.90/paywall is
  retired. Member value is persistence, profile, preferences and eligible
  participation, never coerced payment.
- `MEMBER_ACTIVATION_CONTRACT`: Activation is an intentional value event (for
  example save, follow, RSVP, profile preference or eligible join), not simply
  a registration count.
- `RETENTION_CONTRACT`: Helpful continuity, alerts/preferences, trusted return
  paths, case-status recovery and graceful degradation support return use.
- `GROWTH_MEASUREMENT_CONTRACT`: Measure privacy-governed lifecycle events,
  including support started/submitted/resolved and recovered-after-error where
  appropriate; do not manipulate metrics or treat support as marketing consent.
- `NON_COERCIVE_CONVERSION_CONTRACT`: Explain the specific Member capability
  enabled, use just-in-time disclosure, and retain an honest public fallback.
- `100K_GROWTH_FRICTION_PROTECTION`: One primary decision per screen, plain
  language, recognition over learning, perceived performance, no dead end and
  no empty DUTA. Legal/privacy/safety gates are not weakened for growth.
