# Day 4 — Trusted Read-Only DUTA Tools

Text or voice transcript flows through one deterministic intent router, then the read-only DUTA tool registry, existing DUTA services, source provenance, and the DUTA response. Voice has no separate authority and cannot invoke writes.

The registry provides official-information search, consulate lookup, jobs, communities, and organisations. DUTA Map and news are registered as unavailable because no verified read-only source exists yet. Unavailable or empty results fall back safely without database details or invented answers.

Trust describes provenance only: **A** Official Government, **B** Verified Organisation, **C** Verified DUTA Partner, **D** Community, **E** AI General Knowledge. A generated summary never upgrades trust. Official results preserve their source reference and verification date where available; DUTA neither impersonates an official institution nor submits an appointment, complaint, payment, application, or other write action.
