# KPP-03A Visual QA Rubric
Use observed evidence, not a numerical “10/10” score.

| Criterion | Required evidence | Failure |
| --- | --- | --- |
| Five seconds | Uncoached person identifies audience, value, first action | Ambiguous audience or register-first impression |
| Human relevance | Scene/context review and participant feedback | Stereotype, stock collage or software-only hero |
| Trust | Source/date/executor slots visible in actual states | Unsupported badge or tiny disclaimer |
| Hierarchy | First action found without scanning all modules | Equal-weight widget clutter |
| Mobile | 320–430 widths, keyboard/safe areas, long labels | Clipping, blocked safety, tiny targets |
| Accessibility | Contrast, keyboard, screen reader, zoom, reduced motion | Color-only meaning, lost focus or unreadable text |
| Brand coherence | Wordmark, palette and cross-screen review | Brand/error/safety semantics confused |
| Consistency | Same primitive and state roles across six specimens | Arbitrary sizes, radii or gradients |
| Action clarity | Destination/benefit and cancellation understood | Fake active action or lost intended task |
| Distinct identity | Warm human context and clear Indonesia/Malaysia copy | Generic AI/dashboard template |
| Performance | Sized responsive image and font/network measurements | Hero delays first value or shifts layout |

Current evidence: repository audit and detailed design specifications A–F.
No actual five-second participant test, rendered prototype QA, licensed human
photo approval, production performance test or accessibility certification is
claimed. Founder can approve the integrated direction and request visual renders
before implementation. Asset and rendered QA remain explicit implementation
acceptance work.
