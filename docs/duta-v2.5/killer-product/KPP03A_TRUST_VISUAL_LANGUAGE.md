# KPP-03A Trust Visual Language
Reserve one readable provenance strip below relevant information: source name,
origin type, last checked date, and destination link. 14px, muted ink, 1.5 line
height. Never compress to an unreadable pill cluster.

| Candidate | Treatment | Evidence predicate |
| --- | --- | --- |
| Official source | Institution icon + “Sumber resmi” + institution | Validated official channel record |
| Verified information | Check + precise verification scope | Approved verification workflow; absent evidence means no badge |
| Community | People icon + “Dari komunitas” | Community origin, not official endorsement |
| User report | Document icon + “Laporan—belum ditinjau” | Only governed private/moderated future workflow |
| AI guidance | “Panduan DUTA AI” plus source region | Generated assistance, not official decision |
| Currentness | “Diperiksa [actual date]” | Actual record date; no hard-coded freshness |
| External destination | Named institution + external-arrow label | Validated URL and executor boundary |

These are candidate visual treatments; KPP-03A does not certify new badges or
publish governance data. Missing or stale evidence gets explicit language and a
safe official destination. “Verified” is never synonymous with safe or endorsed.
