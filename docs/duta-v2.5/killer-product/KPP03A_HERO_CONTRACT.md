# KPP-03A Hero Contract
Frozen message: “Teman menjalani hidup di Malaysia.”
Audience eyebrow: “UNTUK ORANG INDONESIA DI MALAYSIA”.
Support: “Tanya DUTA, temukan layanan penting, peluang kerja, dan komunitas
dengan sumber yang bisa Anda periksa.”
Primary: “Tanya DUTA” → existing /tanya. Secondary: “Jelajahi kebutuhan” →
architecture-approved Essential entry. Quiet returning-user Masuk.
Trust cue: “Independen. Bukan layanan pemerintah.” Visible before the first fold.

Desktop: 1200px content, text 52%, image 48%, 48px gap. Human face/gesture
occupies the image right-center, never behind text. Photo 4:5, subject safe box
within central 60%; title and CTA are the strongest readable elements.
Mobile: copy and actions first, 4:3 human crop below; no full-height photo
pushes value below the fold. Use separately art-directed crop, preserving face,
hands and context. On a 390×844 reference viewport, audience/headline/support/
primary/secondary/trust fit before the photo. At shorter screens content scrolls
normally. No text baked into image, autoplay video or parallax.

Image failure/slow network preserves copy, CTA and trust; fixed media aspect ratio
prevents shift. Initial production budget proposal: mobile hero ≤180KB,
desktop ≤300KB, responsive formats and explicit dimensions. These are budgets,
not measured implementation results.
