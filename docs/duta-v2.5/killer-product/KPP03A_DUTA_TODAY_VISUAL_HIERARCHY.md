# KPP-03A DUTA TODAY Visual Hierarchy
Attention order: warm greeting → Cakap/Tanya DUTA interaction → most useful
sourced item → optional contextual content. Persistent Jaga Diri remains visible.

Greeting is plain typography, not a card. Ask uses one white outlined surface.
Penting Hari Ini uses a single editorial row with provenance when real content
exists. Untuk Anda appears only with explainable authenticated context.
Sekitar Anda uses chosen coarse place, never fixed distances. Lanjutkan appears
only with real persisted work; the known missing persistence must not be disguised.

Anonymous: “Ada yang bisa DUTA bantu?” plus useful public shortcuts. New user:
optional context, no fabricated name. Returning: one real continuation item.
Empty: “Belum ada informasi relevan” plus Essential exploration. Denied location:
manual area. Offline/degraded: quiet inline status, preserve navigation.
No equal-sized six-widget dashboard. Prototype C specifies the empty-safe design.
