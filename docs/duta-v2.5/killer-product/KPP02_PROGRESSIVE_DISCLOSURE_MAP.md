# KPP-02 Progressive Disclosure Map

## Levels

- **Level 0 — five-second comprehension:** audience, immediate value, first
  action and independent/non-government boundary.
- **Level 1 — primary intents:** TODAY, ASK DUTA, ESSENTIAL, CONNECT, ME, plus
  persistent Jaga Diri.
- **Level 2 — contextual capability:** the smallest useful set for the selected
  intent.
- **Level 3 — detailed action:** detail, trusted source, join/save/create,
  official handoff or continuation.
- **Level 4 — advanced/control:** privacy, security, managed organization,
  moderation and internal admin.
