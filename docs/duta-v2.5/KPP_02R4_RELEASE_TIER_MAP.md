## Six RI mission representation

All six must be represented in the source-governance release gate: KBRI Kuala
Lumpur; KJRI Johor Bahru, Penang, Kuching and Kota Kinabalu; and KRI Tawau.
Public access is separate from VERIFIED/CURRENT source state. An unavailable or
unverified channel must not receive a RESMI/current claim.
